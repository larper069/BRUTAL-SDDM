AUXIS optional display font

Download HiJO from the official 1001 Fonts page:
https://www.1001fonts.com/hijo-font.html

Extract hijo.zip and copy the HiJO Regular OTF file into this folder, renaming
it to exactly: HiJO-Regular.otf

The QML uses HiJO for the AUXIS wordmark and large clock. Small labels and
controls keep a mono font for readability. Without this file, Qt falls back
to a system font. Please retain the font's included license file.
